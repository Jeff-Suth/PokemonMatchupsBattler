# Pokémon Matchups

A single-page type matchup calculator for Pokémon Generations 1–5 (#001–#649).

Enter the three Pokémon you are facing and the page ranks every attacking type against the whole team, with Gen 5 and modern (Fairy) type charts, Levitate, and each opponent's likely coverage moves.

**Live site:** https://YOUR-USERNAME.github.io/PokemonMatchups/

## Notes

- Everything runs in the browser from `index.html`; there is no build step.
- The screenshot reader, Rotation Battle turn planner and Claude chat use Claude, so they only work when the page is opened as a Claude artifact on claude.ai. On GitHub Pages those sections show a notice, and the type calculator works on its own.
- Opponent coverage moves you add by hand are saved in your browser's local storage.
